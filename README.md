Creative Strategist & Digital Entrepreneur, Founder of Colart Digital Marketing Agency.

Static site: `index.html` + `assets/images/`. No build step.

## Deploy (GitHub Pages)
1. Push to the `main` branch root.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Custom domain: add a `CNAME` file with the domain, then a CNAME DNS record pointing to `atsam01lb.github.io`.
